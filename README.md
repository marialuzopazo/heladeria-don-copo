consignas que se siguieron para este proyecto:

### Página 1 — Landing (index.html)
• header con el nombre (o logo) y un nav con enlaces a las dos páginas.
• Una portada (hero) con un título, un texto breve y una imagen (o un fondo de
color).
• Una sección “Sobre nosotros” con un párrafo.
• Una sección de Contacto con un formulario maquetado: nombre, email, mensaje
y botón. No hace falta que envíe.
• Un footer con datos (dirección, redes, año).

### Página 2 — Productos (productos.html)
• Una grilla de al menos 6 productos en tarjetas, cada una con imagen, nombre y
precio.
• Podés agrupar por categorías (helados, postres, bebidas).
En las dos páginas: el mismo header y footer, y la navegación funcionando entre ambas.

### Requisitos técnicos
# HTML
• Estructura completa en cada página: <!DOCTYPE html>, lang="es", los meta de
charset y viewport, y <title>.
2
• Etiquetas semánticas (header, nav, main, section, article, footer). Evitá div
cuando haya una etiqueta semántica.
• Imágenes con alt, y cada control del formulario con su <label>.
# CSS
• Hoja de estilos externa (styles.css), compartida por las dos páginas.
• Flexbox en el nav (o en el hero).
• Grid en la grilla de productos.
• Una variable CSS (:root) para el color principal, usada al menos dos veces.
• Una media query para pantallas chicas (mobile-first).
• Un efecto :hover con transición (en botones, enlaces o tarjetas).
# Reglas
• Solo HTML y CSS. Sin JavaScript.
• Sin frameworks (Bootstrap, Tailwind, etc.).
• El formulario no envía datos: solo se maqueta y se valida con atributos HTML
(required, type).
